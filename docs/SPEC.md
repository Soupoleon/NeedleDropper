# NeedleDropper — Build Spec (v1)

This file is the **contract** between every component. If you are implementing a component, follow it exactly; if something here is wrong or impossible, say so in your report instead of silently diverging.

Target: **World of Warcraft: Forever** (flavor `wowf`, build 1.60.1.70790, TOC `## Interface: 16001`). Forever runs classic Azeroth content on the Mainline 12.x client and API (incl. Midnight "secret value" restrictions). Host OS: Windows 11. Install: `C:\Program Files (x86)\World of Warcraft\_forever_`.

## 0. The experience

A *needle drop*: the first time a character arrives in a zone (or a hand-picked landmark subzone), after a short "arrival" delay and only when it's calm (no combat, not on a taxi, not dead, no cinematic), a curated song starts, in-game zone music fades away, and a Kojima-style title card appears ("ELWYNN FOREST — Low Roar · I'll Keep Coming"). Silence is the default; drops are rare (global cooldown). Each drop plays once per character (configurable). Songs can be replayed from a journal.

## 2. Architecture

```
 WoW:F client (sandboxed Lua addon)                       Companion (Python, Windows)
 ┌──────────────────────────────────┐   one-way, read-only   ┌────────────────────────────────────┐
 │ Location → Discovery → Director   │  ── pixel beacon ──▶  │ transport.pixel  (GDI screen grab)  │
 │   (first-visit, gates, cooldown)  │  ── chat log  ─────▶  │ transport.chatlog (tail file)       │
 │ Audio (duck zone music,           │                        │        │ dedupe by (seq,type,n,hash)│
 │        in-game local drops)       │                        │      engine ── providers:           │
 │ Toast (title card)                │                        │   spotify (Web API, PKCE, Premium)  │
 └──────────────────────────────────┘                        │   local / youtube (deck page)       │
   Map.lua ◀── generated by companion from packs\*.json       │   applemusic (open link only)       │
                                                              │   deck: 127.0.0.1:8322 now-playing  │
                                                              └────────────────────────────────────┘
```

**Principle:** the addon decides *whether/when* a drop fires (it owns gameplay state & per-character history). The companion only decides *how* to play it. Data flows addon → companion only. The addon is fully useful alone with user-supplied local audio files played in-game.

Strictly read-only toward the game: no memory reading, no DLL injection, no input/keypress injection, no combat data.

## 3. Shared data model

### 3.1 Drop ids (strings, stable)
- zone drop: `zone:<uiMapID>` e.g. `zone:1429`
- landmark by area id: `area:<areaID>` e.g. `area:87`
- landmark by name: `sub:<uiMapID>:<slug>` where slug = lowercase name, every run of non `[a-z0-9]` chars → `-`, trimmed of `-` (e.g. `Lion's Pride Inn` → `lion-s-pride-inn`)
- instance drop: `inst:<instanceID>` (8th return of `GetInstanceInfo()`)
- test drop: `test`

### 3.2 Map.lua (generated by `companion/needledropper/mapgen.py`, read by the addon)
```lua
-- Generated by NeedleDropper companion <version> at <iso time>. Edit packs, not this file.
NeedleDropper_Map = {
  version = 1,
  hash = 40213,                 -- uint16, Fletcher-16 of canonical drop JSON (see 3.4)
  generated = "2026-11-05T18:00:00Z",
  packs = { "Azeroth Unbound" },
  drops = {
    { n = 1, id = "zone:1429", kind = "zone", mapID = 1429, label = "Elwynn Forest",
      title = "I'll Keep Coming", artist = "Low Roar", durationMs = 245000, startMs = 0 },
    { n = 2, id = "area:87", kind = "subzone", mapID = 1429, areaID = 87, subzone = "Goldshire", label = "Goldshire",
      title = "...", artist = "...", durationMs = 0, startMs = 0,
      file = "Interface\\AddOns\\NeedleDropper_Local\\media\\goldshire.mp3" },  -- optional: in-game local playback
    { n = 3, id = "inst:36", kind = "instance", instanceID = 36, label = "The Deadmines", title = "...", artist = "...", durationMs = 0 },
  },
}
```
- `n`: 1..65535, assigned by sorting drop ids (plain string sort) and numbering from 1. `n = 0` means "no drop".
- `durationMs = 0` means unknown (addon uses `settings.maxDropSec`).
- `file` present ⇒ addon may play it in-game (if `settings.localPlayback`), and sets flag `LOCAL_PLAYBACK` on events so the companion does not also play audio.
- Strings are Lua-escaped (`\\`, `\"`, `\n`). File must be valid Lua 5.1. Must also write a sidecar `Map.json` (same content as JSON: `{version,hash,generated,packs,drops:[...]}`) next to `Map.lua` — the companion reads the sidecar to resolve `(hash, n)` → drop.
- A placeholder `Map.lua` + `Map.json` built from the starter pack ships inside the addon (files must exist at client launch; overwriting contents + `/reload` is then enough).

### 3.3 Event (addon → companion)
| type | value | meaning |
|---|---|---|
| NONE | 0 | nothing (beacon idle frame) |
| HELLO | 1 | addon loaded / reloaded / zone settled with nothing pending |
| ARM | 2 | drop `n` is pending (player arrived; waiting for dwell/gates). Companion may prewarm (wake Spotify device, resolve track). |
| FIRE | 3 | play drop `n` now |
| CANCEL | 4 | stop/fade drop `n` (danger, instance, death, `/needle stop`/`skip`), or abandon an ARM |
| PING | 5 | transport self-test; companion logs it, never plays |

Flags (uint8 bitmask): `0x01 IN_COMBAT`, `0x02 IN_INSTANCE`, `0x04 ON_TAXI`, `0x08 DEAD`, `0x10 LOCAL_PLAYBACK`, `0x20 DROP_ACTIVE`, `0x40 TEST` (manual `/needle play|test` — not first-visit), `0x80` reserved (0).

Event fields: `seq` (uint8, increments by 1 mod 256 on every emitted event), `type`, `n` (uint16), `hash` (uint16 Map hash the addon has loaded), `flags`, `id` (string; chat channel only).

### 3.4 Checksums & hash
Fletcher-16 over a byte sequence: `s1 = (s1 + b) % 255; s2 = (s2 + s1) % 255` starting at 0,0; result `s2 * 256 + s1`. (Pure arithmetic — Lua 5.1 has no bit ops.)
Map hash = Fletcher-16 over UTF-8 bytes of `json.dumps([[d["n"], d["id"], d.get("title",""), d.get("artist",""), d.get("durationMs",0)] for d in drops], separators=(",",":"), ensure_ascii=True)`; if the result is 0 use 1.

### 3.5 Pixel beacon (primary channel)
Payload: 10 bytes
```
b0 = 0x4E ('N')                 b1 = 0x10 | type   (version 1 in high nibble)
b2 = seq                        b3,b4 = n (big endian)
b5,b6 = hash (big endian)       b7 = flags
b8,b9 = Fletcher-16 of b0..b7 (b8 = s2, b9 = s1)
```
Bits: concatenate bytes MSB-first (80 bits), append one 0 bit (81 bits), split into 27 cells of 3 bits each, in order (R,G,B): bit 1 → channel 255, bit 0 → channel 0.
Strip = 4 header cells `MAGENTA(255,0,255), GREEN(0,255,0), MAGENTA, GREEN` followed by the 27 payload cells = 31 cells in one horizontal row, each cell `cellPx × cellPx` physical pixels (default 4), top-left of the strip at the top-left pixel of the game's client area.
The addon re-renders on every state change and keeps the strip shown permanently while enabled. When nothing has happened yet the beacon shows a HELLO frame.
Companion decoding: grab the top-left region (default 256×32 physical px) of the WoW client area; locate the header (scan rows; a magenta run of length L followed by green run ≈L, magenta ≈L, green ≈L; L gives cell size); sample each payload cell at its centre; threshold each channel at 128; rebuild bytes; validate b0, version, checksum. Act on a frame only after **2 consecutive identical valid reads**. On companion start, the first valid frame is a *baseline* (not acted on).

### 3.6 Chat-log channel (secondary, opt-in)
Addon: `LoggingChat(true)` (only if `settings.chatlog`), install a `CHAT_MSG_SYSTEM` message filter that hides lines starting with `NDROP1 ` or `NDPAD ` (guard: if `issecretvalue and issecretvalue(msg)` → return false, don't touch). Emit via `SendSystemMessage(line)`.
Line: `NDROP1 <seq> <type> <n> <hash> <flags> <id> <crc>` — decimal integers, `id` with every char outside `[A-Za-z0-9:_.-]` replaced by `_`, `crc` = 4 lowercase hex digits of Fletcher-16 over the bytes of everything before ` <crc>`.
Padding (forces the client's ~48 KiB write buffer to disk): after FIRE, CANCEL and PING, emit `ceil(settings.chatlogPadBytes / 900)` lines `NDPAD <seq> ` + dots to length 900. Default `chatlogPadBytes = 50000`; `0` disables padding. ARM/HELLO are emitted unpadded.
Companion: tail `<install>\_forever_\Logs\WoWChatLog.txt` (open shared read; poll size every 250 ms; read from last offset; handle partial last line; never truncate/modify the file). Match regex `NDROP1 (\d+) (\d+) (\d+) (\d+) (\d+) (\S+) ([0-9a-f]{4})` anywhere in the line; verify crc; ignore `NDPAD`. On start, skip to end of file (don't replay history).

### 3.7 Pack JSON (`packs/*.json`, user editable)
```json
{
  "format": "needledropper-pack", "version": 1,
  "name": "Azeroth Unbound", "author": "...", "description": "...",
  "drops": [
    { "zone": "Elwynn Forest", "title": "I'll Keep Coming", "artist": "Low Roar",
      "spotify": "spotify:track:<id>", "youtube": "<videoId>", "appleMusic": "https://music.apple.com/...",
      "file": "elwynn.mp3", "startMs": 0, "durationMs": 245000, "volume": 80, "note": "why it fits" },
    { "zone": 1429, "subzone": "Goldshire", "areaID": 87, "title": "...", "artist": "..." },
    { "instanceID": 36, "label": "The Deadmines", "title": "...", "artist": "..." }
  ]
}
```
- `zone`: zone name (resolved via `zones.py`, case/punctuation-insensitive) or uiMapID int.
- drop id derivation: instanceID → `inst:`; areaID → `area:`; subzone → `sub:<mapID>:<slug>`; else `zone:<mapID>`.
- Required: `title`, `artist`, plus a location. Everything else optional. Later packs override earlier ones for the same drop id.
- `file`: relative to companion config `local.mediaDir` (companion-side playback) — and if the user also copied it to `Interface\AddOns\NeedleDropper_Local\media\`, `inGameFile: true` makes mapgen emit `file = "Interface\\AddOns\\NeedleDropper_Local\\media\\<file>"`.

### 4.1 Verified API facts (from research against the Forever 70790 UI source — rely on these)
- Zone: `C_Map.GetBestMapForUnit("player")` → uiMapID (Classic-style ids: Elwynn 1429, Durotar 1411, Stormwind 1453 …; new Forever zones: Mount Hyjal 2482, Zephras Isle 2521, Riverglades 2548, Shen'dralas 2652). It returns the *lowest* map (city/microdungeon); normalize by walking `C_Map.GetMapInfo(id).parentMapID` up while `mapType > 3` (Enum.UIMapType: 0 Cosmic,1 World,2 Continent,3 Zone,4 Dungeon,5 Micro,6 Orphan). If the final mapType < 3 → no zone key. Do not key on `PLAYER_MAP_CHANGED` payload; just re-read the map on it.
- Subzone: `GetSubZoneText()` (localized, "" if none; may be empty right at login — retry with `C_Timer.After`). `GetZoneText()`, `GetRealZoneText()`, `GetMinimapZoneText()`. `C_Map.GetAreaInfo(areaID)` → localized area name.
- Instance: `IsInInstance()` → inInstance, instanceType; `GetInstanceInfo()` 8th return = instanceID. `C_Map.GetPlayerMapPosition` returns nil in instances.
- Events: `ZONE_CHANGED`, `ZONE_CHANGED_INDOORS`, `ZONE_CHANGED_NEW_AREA`, `PLAYER_ENTERING_WORLD(isInitialLogin, isReloadingUi)`, `PLAYER_MAP_CHANGED`, `MAP_EXPLORATION_UPDATED` (no payload; also fires at login), `UI_INFO_MESSAGE(errorType, message)`, `PLAYER_REGEN_DISABLED/ENABLED`, `PLAYER_DEAD`, `PLAYER_ALIVE`, `PLAYER_UNGHOST`, `PLAYER_CONTROL_LOST/GAINED`, `CINEMATIC_START/STOP`, `PLAY_MOVIE`, `STOP_MOVIE`, `LOADING_SCREEN_ENABLED/DISABLED`, `PLAYER_LOGOUT`, `SHARD_TRANSFER` (debounce), `UI_SCALE_CHANGED`, `DISPLAY_SIZE_CHANGED`.
- Discovery ("first time" from the server): on `UI_INFO_MESSAGE(errorType, msg)` call `GetGameMessageInfo(errorType)` → first return `errorName`; discovery iff `errorName == "ERR_ZONE_EXPLORED" or errorName == "ERR_ZONE_EXPLORED_XP"`. The discovered area is the current `GetSubZoneText()` (or parsed from msg). Backup: `CHAT_MSG_SYSTEM` matched with a pattern built from `_G.ERR_ZONE_EXPLORED` / `_G.ERR_ZONE_EXPLORED_XP` (escape magic chars, `%s`→`(.+)`, `%d`→`%d+`) — guard secret values. `UI_INFO_MESSAGE` is dispatched at end of frame; correlate with zone/subzone changes within a ~2 s window.
- History: `C_MapExplorationInfo.GetExploredMapTextures(uiMapID)` → array (non-empty ⇒ character explored part of that zone). `C_MapExplorationInfo.GetExploredAreaIDsAtPosition(uiMapID, pos)` with `pos = C_Map.GetPlayerMapPosition(uiMapID, "player")` → array of explored areaIDs at the player's position (outdoors only).
- Gates: `UnitAffectingCombat("player")`, `UnitIsDeadOrGhost("player")`, `UnitOnTaxi("player")`, `InCinematic()`, `MovieFrame and MovieFrame:IsShown()`, `C_RestrictedActions.IsAddOnRestrictionActive(Enum.AddOnRestrictionType.Encounter)` (guard existence).
- Audio: `PlayMusic(path)` plays/loops a file in the music slot and fades out built-in zone music; `StopMusic()` stops it. `PlaySoundFile(path, "Music")` → `willPlay, handle` (willPlay nil if blocked/missing). `StopSound(handle, fadeoutMs)`. `C_Sound.IsPlaying(handle)` (use `pcall`). Addon audio files must exist when the client starts (new files need a client restart). No event fires when a sound ends — poll or use stored duration.
- CVars: `C_CVar.GetCVar/SetCVar` (or `GetCVar/SetCVar`) for `Sound_EnableMusic`, `Sound_MusicVolume`. Never set `Sound_EnableMusic = 0` to mute zone music during a drop (it would mute in-game drops too).
- Chat: `LoggingChat(bool)`, `C_ChatInfo.IsLoggingChat()`, `SendSystemMessage(text)`, `ChatFrameUtil.AddMessageEventFilter(event, fn)` (fallback `ChatFrame_AddMessageEventFilter`). Secret: `issecretvalue(v)`, `C_ChatInfo.InChatMessagingLockdown()` (defer chat emits while true).
- Pixels: `PixelUtil.GetPixelToUIUnitFactor()` (= 768 / physical height) or `768 / select(2, GetPhysicalScreenSize())`. Physical px → frame units: `px * factor / frame:GetEffectiveScale()`.
- Settings: `Settings.RegisterVerticalLayoutCategory(name)`, `Settings.RegisterAddOnSetting(category, variable, variableKey, variableTbl, varType, name, default)`, `Settings.CreateCheckbox(category, setting, tooltip)`, `Settings.CreateSlider(category, setting, options, tooltip)` with `Settings.CreateSliderOptions(min,max,step)`, `Settings.CreateDropdown(category, setting, getOptionsFn, tooltip)` with `Settings.CreateControlTextContainer()` (`:Add(value,label)`, `:GetData()`), `Settings.RegisterAddOnCategory(category)`, `Settings.OpenToCategory(category:GetID())`. Use `pcall` around all of it.

### 4.3 Director behaviour (state-based, 1 Hz ticker + event nudges)
- Track `zoneKey/zoneEnteredAt`, `subzone/subEnteredAt`, `instanceID`, `lastDiscovery = {name, t}`. On any zone event wait 0.5 s then re-read (debounce flapping and `SHARD_TRANSFER`).
- Candidates (priority): instance drop (if in instance & `instanceDrops`) > landmark drop for current subzone > zone drop for current zone. A candidate is eligible if mapped, not done (per scope), `enabled`.
- When a candidate first becomes eligible → emit **ARM** once (per entry). If the key changes before FIRE → emit **CANCEL** for the armed `n` (not marked done).
- FIRE when: dwell satisfied (zone: `now - zoneEnteredAt >= dwellSec`, or a discovery in this zone since entry and `>= minDwellSec`; landmark: discovery for this subzone or `>= landmarkDwellSec`; instance: `>= minDwellSec`), all gates clear (not combat, not dead/ghost, not taxi if `suppressOnTaxi`, not cinematic/movie/loading, not encounter-restricted, not in an instance unless instance drop), cooldown clear (`now - lastFireAt >= cooldownMin*60`, `lastFireAt` persisted in char DB), and no drop currently active. Pending drops wait while gates fail (no timeout while the player remains there).
- On FIRE: mark done (`how="played"`), append journal, set active drop, Audio duck (+ local playback if `file` and `localPlayback`), Toast, emit FIRE (flags incl. `LOCAL_PLAYBACK` if playing in-game).
- Active drop ends at `durationMs` (or `maxDropSec` if 0; for local playback when `C_Sound.IsPlaying` turns false) → Audio restore → emit HELLO (beacon idle). Leaving the zone does **not** stop it.
- CANCEL active drop on: combat lasting `> combatFadeSec` (if >0), death, entering an instance (unless instance drop), `/needle stop` or `/needle skip`. Audio restore with fade.
- Respect history (`historyMode="respect"`): zone drops — once per character per drop id (record in `scanned`), on login after ~3 s, if `#GetExploredMapTextures(mapID) > 0` → mark done `how="history"`. Landmark drops with `areaID` — on entering the subzone, wait 1.5 s; if no discovery for this subzone happened in the last ~3 s and `areaID` is in `GetExploredAreaIDsAtPosition(...)` → mark done `how="history"`. No evidence ⇒ treat as new.
- New character: if a cinematic/movie is playing, wait for `CINEMATIC_STOP`/`STOP_MOVIE`; retry map reads when they return nil.

### 4.4 Audio
- duck (`duckMethod="silence"`): `PlayMusic("Interface\\AddOns\\NeedleDropper\\media\\silence.mp3")` (fades zone music). `"volume"`: save `Sound_MusicVolume` to `NeedleDropperDB.savedCVars`, prefer `C_CVar.SetTempCVar` when available, else set to "0". `"none"`: nothing.
- restore: `StopMusic()`; if `kickZoneMusic` and `Sound_EnableMusic=="1"`: set "0" then after 0.1 s back to "1" (restarts zone music). Volume method: restore saved CVar and clear `savedCVars`. On `PLAYER_LOGIN`, if `savedCVars` is non-nil (crash), restore it.
- local drop: `PlaySoundFile(file, "Music")`; if `willPlay` falsy → treat as no local file (let the companion play: clear `LOCAL_PLAYBACK`). Stop with `StopSound(handle, 3000)`.

### 4.5 Toast (title card)
Centered at ~22% from the top, no mouse interaction, `FULLSCREEN_DIALOG` strata: line 1 the place label in large spaced caps (e.g. `E L W Y N N   F O R E S T` style letter-spacing via the font string or simply uppercase), line 2 `Artist · Title` smaller. Fade in 1.5 s, hold 6 s, fade out 2 s (use `UIFrameFadeIn/Out` if present else OnUpdate alpha). Respect `settings.toast`.

### 4.6 Slash commands (`/needle`, `/nd`)
`help` · `status` (settings summary, transports, map hash/#drops, pending/active, cooldown left) · `where` (prints current zone key, uiMapID, subzone, instanceID, matching drop ids — for pack authoring) · `journal` · `replay [id]` (replays last or given drop with flag TEST; does not touch done) · `play <id|zone name>` (TEST) · `test` (fires drop `test` n=0 with TEST flag; toast "NEEDLEDROPPER TEST") · `stop` · `skip` (cancel + keep done) · `reset char|account|all` · `beacon on|off` · `chatlog on|off` · `selftest [chatlog|discovery|music|beacon]` · `debug on|off` · `options`.

### 4.7 Self-test (`/needle selftest`) — validates the unverified assumptions on the user's real client
- `beacon`: show beacon, emit PING, print "companion `diag` should show PING seq N".
- `chatlog`: report `C_ChatInfo.IsLoggingChat()` / whether `LoggingChat(true)` stuck (if not: tell user to type `/chatlog`); emit one unpadded PING, then pad in 8 KB steps once per second up to 64 KB, printing cumulative bytes, so the user can read in companion `diag` at which size the PING landed.
- `discovery`: for 120 s, print every `UI_INFO_MESSAGE` errorName + message and every `MAP_EXPLORATION_UPDATED`, plus `GetBestMapForUnit` / normalized zone / subzone on each zone event.
- `music`: duck for 8 s then restore; ask the user whether zone music returned.

### 5.3 Engine
Receives `(Event, transportName)` from all transports on worker threads → single engine thread via `queue.Queue`. Dedupe by `(seq, type, n, hash)` for 15 s. Resolve drop via `(hash, n)` from addon `Map.json` / `maps\<hash>.json`; `n=0` with TEST → "test" drop (plays a configurable test track or just shows the card).
- HELLO: mark addon alive; if a drop is playing that the addon no longer reports active (no `DROP_ACTIVE` flag) for >5 s → stop it.
- ARM: `provider.prepare(drop)` for the first provider that `can_play` (best effort, never raises).
- FIRE: deck shows title card. If `LOCAL_PLAYBACK` flag → no audio. Else try providers in configured order: `can_play(drop)` → `play(drop, fade_in_ms)`; on `ProviderError` try next. Schedule auto-stop at `startMs + durationMs` (if known) or rely on `provider.poll()`.
- CANCEL: `stop(handle, fade_out_ms)`; if `n` was only armed → nothing.
- PING: log `PING seq=… via <transport>` prominently.
- A new FIRE while one plays → stop the old one first.

### 5.4 Providers
- `spotify`: Web API, Authorization Code + PKCE, redirect `http://127.0.0.1:<redirectPort>/callback` (user registers exactly that), scopes `user-modify-playback-state user-read-playback-state`. Requires Premium; each user registers their own Spotify app (Development Mode). Flow: snapshot `GET /v1/me/player` → pick device (`GET /v1/me/player/devices`: configured name → type Computer → active → first non-restricted; if none, `os.startfile("spotify:")` and poll ≤10 s) → `PUT /v1/me/player/play?device_id=…` `{uris:[uri], position_ms:startMs}` → optional volume fade via `PUT /v1/me/player/volume` (≤8 steps; tolerate 403/404 on volume) → at end: fade, `PUT /v1/me/player/pause`, restore volume, restore snapshot if it was playing. Poll `GET /v1/me/player` while playing to detect the user skipping/changing tracks (→ stop managing). Resolve missing `spotify` uri / `durationMs` via `GET /v1/search?type=track&limit=10&q=track:"<title>" artist:"<artist>"` with normalized best-match, cache in `cache\resolved.json`; `GET /v1/tracks/{id}` for duration if needed. Errors: 401 → refresh once; 403 → `ProviderUnavailable("Spotify Premium required or app not allowlisted")` for the session; 404 → wake device then retry once; 429 → honour `Retry-After` (≤5 s) else fail. Token: refresh token stored with DPAPI (`secrets.py`, ctypes `CryptProtectData`). `now_playing()` returns album art url, track/artist, Spotify link, `attribution="Spotify"`.
- `local`: plays `drop.file` (resolved against `local.mediaDir`) through the deck page (HTML5 `<audio>`, seek to startMs, JS volume fades). Requires deck connected.
- `youtube`: plays `drop.youtube` video id in the deck page's IFrame Player (visible, ≥200×200, `origin` playerVar = page origin, `startSeconds`), handles onError 100/101/150/153 → error. Requires deck connected.
- `applemusic`: no automation exists on Windows; if `drop.appleMusic` url: open it with `os.startfile` and show the card ("press play in Apple Music"). Counts as success.

### 5.5 Deck (now-playing page, `deck/server.py`)
`ThreadingHTTPServer` on `127.0.0.1:<deck.port>`: `GET /` static page; `GET /events` Server-Sent Events stream of JSON commands `{cmd: "show"|"play"|"stop"|"fade"|"hide", ...}`; `POST /status` JSON `{state: "ready"|"playing"|"ended"|"error"|"autoplay-blocked", detail}`; `GET /media/<token>` serves a whitelisted local file (Range support for seeking). Page: dark, cinematic title card (place label, artist · title, cover art if given, provider attribution), hidden-by-default YouTube player area that becomes visible (≥ 320×180 … keep ≥200×200 container) when YouTube plays, `<audio>` for local. Shows "Click once to enable sound" overlay until a user gesture. Auto-open: Edge `--app=http://127.0.0.1:8322/ --window-size=480,640` (fallback `webbrowser.open`).

### 5.6 CLI (`python -m needledropper <cmd>`)
`setup` (interactive: WoW path, providers, Spotify client id + login, install addon, build map) · `spotify-login` · `install-addon [--force]` (copy `addon\NeedleDropper` → AddOns; warn if `_forever_\Wow.exe` running; never delete user files in `NeedleDropper_Local`) · `build-map` (packs → `Map.lua`+`Map.json` in installed addon and `maps\<hash>.json`; atomic write; prints "type /reload in game") · `resolve` (Spotify-resolve all drops missing uri/duration) · `run` (transports + engine + deck; Ctrl+C to quit) · `diag` (print every decoded beacon frame / chat line / chat-log file growth; no playback) · `test-drop <id|zone name>` (play through providers without the game) · `zones` (list known zones) · `validate` (lint packs).
